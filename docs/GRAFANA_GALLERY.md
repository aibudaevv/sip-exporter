# Grafana Dashboard Gallery

[Русская версия](GRAFANA_GALLERY.ru.md)

All 11 sections of the production dashboard, captured from the released `1.11.0` image with
deterministic synthetic SIP/RTP lab traffic. Optional panels show `No data` when the capture profile
does not emit that signal, such as RTCP endpoint reports or parser errors; this is not a query error.
